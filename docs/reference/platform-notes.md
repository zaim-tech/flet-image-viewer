# Platform notes

The extension supports Android, iOS, Linux, macOS, and Windows. Web is not
currently supported.

| Platform | Support |
| --- | --- |
| Android | Supported |
| iOS | Supported |
| Linux | Supported |
| macOS | Supported |
| Windows | Supported |
| Web | Not supported |

Use the native build target for the platform you are testing. For mobile
packages, follow the standard Flet requirements for Android and iOS builds.
